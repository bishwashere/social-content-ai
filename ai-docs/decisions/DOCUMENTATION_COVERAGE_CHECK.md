# Documentation coverage check (nextpostai.com/documentation)

Checked live docs on 2026-02-10. Summary of what is documented vs missing for major features.

## Documented on the site

- **Quick Generate** — Multi-platform AI content, prompt → generated posts, history, scheduling. No mention of dashboard chat UI or Instagram card actions.
- **Campaign Planner** — Multi-day campaigns, planning, scheduling.
- **Video Features** — Quick Video Maker (dashboard/sidebar, no project required, 3 steps: template → hook → demo video), templates, My Videos, campaign integration.
- **Analytics & Insights** — Project Pulse (health score), platform analytics, consistency tracking. **Does not mention AI campaign suggestions** (new campaign ideas from performance data).
- **Blog News** — Auto blog from trending articles, webhook integration, duplicate prevention, flow (fetch → generate → webhook).
- **Content Discovery** — Documented as **social wall/feed** (browse community posts, For You, Templates). **Not** the Brand Discovery / Ad Discovery tool.
- **Scheduled Posts**, **Automation**, **Templates Library**, **Advanced Customization** — Listed and linked.
- **Project Management** — Index lists "Project folders, team collaboration" (project-management page timed out when fetched).
- **Platforms** — Facebook, Instagram, LinkedIn, Twitter, TikTok, Threads, Reddit.
- **Integrations** — Webhooks (blog posts); API reference "Coming soon".
- **Pricing & Billing** — Plans, free credits (e.g. 100 to start), credits system, billing. No explicit "welcome offer popup" or "credit confirmation dialogs".

## Not documented (or different feature)

1. **AI campaign suggestions** — Analytics doc has Pulse and metrics only; no section on AI-generated campaign ideas from performance.
2. **Brand discovery & ad creative generation** — Questionnaire + 40+ Facebook ad concepts. Not the same as "Content Discovery" (wall/feed). No doc for Tools / Brand Discovery / Ad creatives.
3. **Referral system** — No section. Super admin, referral partners, unique links, click/signup tracking, partner dashboard.
4. **Ad discovery & image generation for creatives** — Add Discovery / ad creatives / image gen not covered anywhere.
5. **Dashboard chat** — Chat in dashboard, project creation from chat, visibility control, Instagram card actions (rewrite, image gen, edit, copy, post). Quick Generate is the closest but does not describe this.
6. **Welcome offer & credit confirmation** — Welcome offer popup with countdown; credit confirmation dialogs before ad generation. Pricing doc mentions credits but not these flows.

## Recommendation

Add or extend docs for: (1) AI campaign suggestions under Analytics & Insights, (2) Brand Discovery / Ad creatives (separate from Content Discovery), (3) Referral system (admin/partner), (4) Dashboard chat and Quick Generate enhancements, (5) Ad discovery & image gen, (6) Welcome offer and credit confirmation flows.
